## 📖 Sobre o Projeto

**Jogo-VisualNovel** é um projeto de jogo narrativo (Visual Novel) focado em escolhas ramificadas, diálogos interativos e construção de personagens. O jogador assume o controle das decisões do protagonista, moldando o rumo dos acontecimentos e alcançando diferentes finais.

## ✨ Funcionalidades

- [x] **Narrativa Ramificada:** Suas decisões influenciam diretamente o desfecho da história.
- [x] **Galeria de Personagens:** Sprites com diferentes expressões e reações emocionais.
- [x] **Múltiplos Finais:** Diferentes rotas para desbloquear e explorar.
- [x] **Trilha Sonora & Efeitos:** Efeitos de áudio e música ambiente para imersão narrativa.
- [x] **Sistema de Salvamento:** Opções para salvar, carregar e rever diálogos anteriores (backlog/histórico).

## 🚀 Como Executar o Projeto

### Pré-requisitos

Certifique-se de ter instalado em sua máquina:
- Git instalado ([git-scm.com](https://git-scm.com/))
- A engine ou interpretador do projeto (ex.: Ren'Py SDK / Python / Godot)

### Passo a Passo

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/joa0filipe/Jogo-VisualNovel.git
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd Jogo-VisualNovel
   ```

3. **Execução:**
   - **Caso utilize Ren'Py:**
     1. Abra o inicializador do Ren'Py.
     2. Adicione a pasta deste projeto ao seu diretório de projetos.
     3. Selecione o jogo e clique em **Launch Project**.
   - **Caso seja executável direto:**
     Basta rodar o arquivo executável gerado para seu sistema operacional (Windows/Linux/Mac).

